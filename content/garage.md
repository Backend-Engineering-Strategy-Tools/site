### Scripted Parts

The rack accessories above are sourced from Printables — download, slice, print. The hole box is different: geometry generated by a Python script running inside Blender, not modelled by hand.

The immediate need was a support brace for the rack — a 220×150×8mm plate with 40 through-holes in a specific alternating-spacing pattern, the B.E.S.T label engraved into the top face, exported directly to STL. Writing it in Python means the layout lives in a config block at the top of the file. Changing hole count, plate dimensions, or row spacing is a constant, not a modelling operation. I iterated on it with Claude: describe what needs to change, get updated Python back, run, look at the viewport, repeat.

The script runs in Blender's Script Editor — open it, press Alt+P, it builds the plate and exports the STL.
